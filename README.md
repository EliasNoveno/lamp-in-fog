 Lamp in Fog 🌫️

 Installation

macOS
1. Download `Lamp in Fog.dmg`
2. Drag to Applications folder
3. If you see a security warning, right-click → Open

Windows
1. Download `Lamp in Fog.exe`
2. Run the installer

 Linux
1. Download `Lamp in Fog.AppImage`
2. Make executable: `chmod +x Lamp\ in\ Fog.AppImage`
3. Run: `./Lamp\ in\ Fog.AppImage`

Troubleshooting
